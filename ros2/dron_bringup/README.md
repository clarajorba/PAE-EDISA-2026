# dron_bringup

Paquete para arrancar el dron con un solo comando. Todavía está vacío.

| Carpeta | Qué irá aquí |
|---|---|
| `launch/` | Launch files: MAVROS para PX4 (`/dev/ttyACM0:921600`), SLAM, puente `vision_pose`, misión |
| `config/` | Configuración de MAVROS, TF estática `base_link → lidar`, parámetros de PX4 (`.params`) |
